# Musical Instruments Explorer

An interactive web application that presents musical instruments from different cultures, regions, and instrument families. The project combines informative content with dynamic filtering, search, favorites, and responsive UI components.

## Overview

**Musical Instruments Explorer** is designed as a digital catalogue for discovering instruments from around the world. Users can browse instruments by category and region, search for specific instruments, view detailed information, discover random instruments, and maintain a personal favorites collection.

The project focuses on building a structured, responsive, and interactive front-end experience using core web technologies.

## Key Features

* **Instrument Catalogue**
  Browse a curated collection of instruments from different musical traditions.

* **Search Functionality**
  Quickly find instruments by name or related information.

* **Category Filtering**
  Filter instruments based on families such as Strings, Percussion, Wind, Brass, Keyboard, and Electronic.

* **Regional Filtering**
  Explore instruments according to their geographical and cultural origins.

* **Instrument Details**
  View additional information through an interactive details modal.

* **Random Discovery**
  Discover an instrument randomly from the available collection.

* **Favorites Collection**
  Save preferred instruments and access them later using browser Local Storage.

* **Responsive Interface**
  Optimized for desktop, tablet, and mobile screen sizes.

* **Educational Sections**
  Includes information about instrument families, sound production, musical history, and interesting facts.

* **Image Gallery**
  Provides visual references for different instruments and musical traditions.

## Getting Started

### Prerequisites

A modern web browser is sufficient to run the project.

For development, **Visual Studio Code** with the **Live Server** extension can be used.

### Installation

Clone the repository:

```bash
git clone https://github.com/your-username/musical-instruments-explorer.git
```

Navigate to the project directory:

```bash
cd musical-instruments-explorer
```

Open `index.html` in a browser, or launch it using Live Server.

## Usage

1. Browse the available instrument categories.
2. Use the search field to locate a specific instrument.
3. Apply category or regional filters.
4. Select an instrument to view detailed information.
5. Use the random discovery feature to explore another instrument.
6. Add instruments to the favorites collection.
7. Access saved favorites during future visits from the same browser.
